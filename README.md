A tiny Node 22 (stdlib-only) program that writes one funny line — the GPS's excuse for sending the driver down the wrong road — to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

## The line

> The shortcut was 400 metres shorter. I never promised those 400 metres would include a road, a bridge, or fewer goats.
